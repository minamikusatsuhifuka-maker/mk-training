### 2-2. 段をつらぬく「3つの柱」（2026-10-23 院長の決定）

どの段でも見る3つの柱を、段ごとに少しずつ深まる形で割り振ります。G1→G1+→G2 は院長の言葉どおりに、G2+ 以上は各段の条件とあわせて割り振りました。

- **柱1 学び続けるコミット**（アチーブメントの学びを続けると決め、続けている）
- **柱2 理念**（知る → 理解する → 完全に理解し実践し始める → 体現する）
- **柱3 願望とキャリアの方向性**（アチーブメントピラミッド：願望 → 人生理念 → 人生ビジョン → 目標 → 計画 → 日々の実践）

| 段 | 柱1 学び続けるコミット | 柱2 理念 | 柱3 願望とキャリアの方向性 |
|---|---|---|---|
| G1 | テクノロジーコースの受講を自分で決め、日程を決めている | **知る**：クリニック理念4つとフィロソフィー7つを覚え、言える | **願望を書き出し始める**：「私は何を求めているのか？」（セルフカウンセリング）に自分の答えを書いている |
| **G1+** | **コミットする**：テクノロジーコースを受講し、「学び続ける」ことを院長との1on1で自分の言葉で約束している。学びを1つ業務で使った事実がある | **理解する**：理念とフィロソフィーの意味を自分の言葉で説明でき、理念に沿った自分の行動の事実を1つ以上語れる | **願望が見え始める**：大切にしたいこと・なりたい姿（願望）と人生理念（仮）を書き、1on1で共有している。当院で伸ばしたい方向の候補を、やりたいこと・できること・求められていること（WANTS・CAN・MUST）の重なりから挙げられる |
| **G2** | **続ける**：テクノロジーコースの再受講（年1〜2回）を自分の年間計画に入れて実行している。学びを同期・後輩に分かち合っている | **完全に理解し、実践し始めている**：判断に迷った場面で理念に照らして選んだ事実がある。新しく入った人に理念を自分の言葉で伝えられる | **願望とキャリアの方向性が明確**：人生理念と人生ビジョンを持ち、どの専門性を伸ばし当院でどんな役割を担いたいかを自分の言葉で語れる。それを可能性ノートの半期の目標に落とし込んでいる |
| G2+ | 次の学び（ダイナミックコース）を自分で選んで受講し、学びの計画を自分で立てている | **体現しようとする**：仲間の行動の中に理念を見つけて伝えている（承認） | 人生ビジョンと当院の理念の重なりを語れる。G3に向けた成長の計画を自分で立てている |
| G3 | 学んだことを後輩に教えている（学びの伝達者） | **体現する**：理念を体現し、お手本になっている | 人生理念から日々の実践まで一貫している（アチーブメントピラミッドが通っている） |
| G3+ | 後輩の学びの計画づくりを支えている | 理念をチームの判断の拠り所として使う場をつくっている | 後輩の願望の明確化を、1on1で支えている |
| G4 | 組織が学び続ける場を設計している | 採用・育成の文脈で理念を語れる | 組織の目的と一人ひとりの願望を重ねる関わりができている |
| G5 | 学びを業界・社会へ広げている | 理念を社会の文脈で語り、遺している | 物心両面の豊かさを、自らの生き方で示している |

**「理念を完全に理解している」の確かめ方（G2）**
- クリニック理念4つとフィロソフィー7つの一つひとつを、意味と具体的な行動の例とともに、自分の言葉で説明できる
- 判断に迷った場面で、理念に照らして選んだ事実を語れる
- 新しく入った人に、理念を自分の言葉で伝えたことがある

**「願望とキャリアの方向性が明確」の確かめ方（G2）**
- 人生理念と人生ビジョンを書いたものがある（テクノロジーコースのワークを使ってよい）
- 当院で伸ばしたい専門性・担いたい役割を、理由とともに語れる
- それが可能性ノートの半期の目標につながっている
- ※中身の良し悪しは見ない。本人が明確にし、言葉にしていることを見る（願望は一人ひとり違ってよい）

### 1. この道しるべのねらい
- 一人ひとりが、**ステップを一つずつ着実に行えば成長できる**ように、等級の段ごとに「やること」をタスクの大きさまで分けて示す
- 当院の人材育成の方針（アチーブメントの教え・選択理論・リードマネジメント）に沿う
  - 本人が自分で選ぶ（押しつけない）
  - 年数で決めない。早く進めたい人にはチャンスを、じっくり深めたい人にはそのペースを
  - 心の中（虚）ではなく、言動と成果に現れた「実（じつ）」を見る
  - 学びは「学ぶ → 実践 → 分かち合う」で完了する

### 2. 全体の地図（8段のはしご）

| 段 | 名前 | ひとことで | 主な道しるべ |
|---|---|---|---|

| 4 | G2+ ★ | 在り方の時代へ踏み出す | 1on1（RWDEP）へ、外的コントロールを用いない、勉強会で発表、リードマネジメント |
| 5 | G3 リーダー ★ | 体現する・伴走する | 育てる人を育てる、場を1回つくる、任せて待つ、水質を守る、ピークパフォーマンス |
| 6 | G3+ | 育成者・設計者を試す | リーダーを育てる、勉強会を主催、入職90日の流れを設計、院外発信を始める |
| 7 | G4 パートナー | 引き出す・支える | 学びの場を組織の仕組みに、経営の視点、代価の先払い |
| 8 | G5 アンバサダー | 広げる・創る | 主催を譲り背中で見せる、学会で発表、理念を後世に遺す |

**どの段でもつらぬく「3つの柱」**
1. 学び続けるコミット
2. 理念（知る → 理解する → 完全に理解し実践し始める → 体現する → 社会で語る）
3. 願望とキャリアの方向性（アチーブメントピラミッド：願望 → 人生理念 → 人生ビジョン → 目標 → 計画 → 日々の実践）

### 3. 道しるべの使い方

#### 3-1. ステップの読み方
どのステップも、次の6つで書いてある。
- やること／できた目安（目に見える事実）／根拠の残し方／目安の時期／支える人／使う教材

#### 3-2. 技能の4段階
①見学 → ②支えがあればできる → ③一人でできる → ④教えられる
- G1〜G2：③へ　G2〜G3：④へ　G3〜G4：教える仕組みをつくる

#### 3-3. 3つの時間軸
| 時間 | すること | 場所 |
|---|---|---|
| 半期 | 今の段のステップから、本人が**3つ**選んで目標にする | 可能性ノート（半期面談・年次対話で振り返る） |
| 月 | 3つの目標から、今月のテーマを**1つ**決める | 1on1 |
| 週 | 今週の一歩を1つ行う | 成長の行動例・今週のひとこと |

#### 3-4. 学びの3点セット
① 学ぶ → ② 1か月以内に職場で1つ使う → ③ 学びメモか朝礼などで分かち合う。3つそろって完了。

#### 3-5. 段を移るとき
- 中間の段（G1+・G2+・G3+）へ：今のステージが直近1半期で安定し、その段のステップがそろったとき
- ステージ（G2〜G5）へ：その条件が直近2半期続けて安定しているとき
- どちらも、半期面談（夏）・年次対話（冬）で、本人の自己評価を起点に対話で合意する

### 0. 院長の決定（2026-10-26）
1. 等級の段ごとに、タスクの大きさまで分けた「ステップ」で道しるべを示す（ステップマップ）
2. 業務の技能は「4段階チェック」で確かめる
3. 半期・月・週の3つの時間軸で、ステップを日々の行動につなげる
4. 最初は G1 → G1+ → G2 から作る。できたら上の段へ広げる
5. 参加必須のセミナーと学び（院外・ブックの章・mk-training の学び）をステップに入れ、「学ぶ → 実践 → 分かち合う」の3点セットで完了とする（学びの地図 v1）

### 1. 仕組み

#### 1-1. ステップの書き方（どのステップも同じ6つ）
| 項目 | 中身 |
|---|---|
| やること | 何をするか（行動で書く） |
| できた目安 | 目に見える事実で書く（「〜できた」「〜を○回」） |
| 根拠の残し方 | どこに何を残すか（可能性ノート・日々の気づき・1on1の記録・先輩の確認 など） |
| 目安の時期 | 入職や段に入ってからの目安。**早くてもよい。遅れても責めない**（年数で決めない当院の考え方のまま） |
| 支える人 | 先輩（G2+のペア共有）、1on1の担当（G3以上）、院長 |
| 使う教材 | コーポレートデザインブック、マニュアル、資料庫、アチーブメントの学び など |

#### 1-2. 技能の4段階
| 段階 | 状態 | 確かめ方 |
|---|---|---|
| ①見学 | 先輩の実施を見て、流れと注意点を言える | 見学の記録＋流れを口で説明 |
| ②支えがあればできる | 先輩が横にいれば、最後まで実施できる | 先輩の確認（1回） |
| ③一人でできる | 一人で正確・安全に実施できる | 一人での実施3回＋先輩の確認 |
| ④教えられる | 後輩に教え、②まで導ける | 後輩の②の確認（G2+以上で使う） |

- 「③一人でできる」の確認は、その業務が④の先輩が行う（いなければ院長）
- 安全にかかわる業務は、③の前に必ず②を通る

#### 1-3. 3つの時間軸
| 時間 | すること | 場所 |
|---|---|---|
| 半期 | 今の段のステップから、本人が**3つ**を選んで半期の目標にする（技能から1つ・マインドか分かち合いから1つ・3つの柱から1つ） | 可能性ノートの目標（半期面談・年次対話で振り返る） |
| 月 | 3つの目標から、今月のテーマを**1つ**決める | 1on1 |
| 週 | テーマに向けた「今週の一歩」を1つ決めて行う | 成長の行動例・今週のひとこと |

- 目標は本人が選ぶ（押しつけない）。選択理論の「自分で選んだことは続く」を大切にする
- 1on1では「今のステップのどこまで来たか」「次の一歩は何か」を一緒に確かめる

#### 1-4. 学びのステップ（学びの地図 v1 とつなぐ）
- 学びのステップは「学ぶ → 実践 → 分かち合う」の3つがそろって完了
  - ① 学ぶ：受講する・読む
  - ② 実践：1か月以内に職場で1つ使う
  - ③ 分かち合う：学びメモか、朝礼・ペア共有で話す
- ステップ表の「区分」が「学び」「ブック」の行は、この3点セットで完了を確かめる
- 全8段の学びは「成長の道しるべ　学びの地図（全8段）」にまとめてある
