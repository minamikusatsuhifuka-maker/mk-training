# 欲求別 成長支援ガイド（院長・幹部用）
## STEP2-3　力の欲求（達成／承認／貢献／競争）

- 型：項目ごとに、欲求が強い人／低い人それぞれ「表れ・成長支援・能力開発・声かけ例・避けたい関わり」
- 前提：STEP1の7原則と「七つの実と、数字の扱い」
- **当院の原則**：個人の成績数値（ノルマ・ランキング）はつくりません。数字は努力の鏡です。力の欲求は、等級要件のクリア・できるようになったこと・チームの挑戦・相手からの感謝で満たします。

---

## 項目5　達成
意味：やり遂げたい、責任を果たしたい、結果を残したい

### 欲求が強い人

**表れ**
- 目標があると燃え、最後までやり切る力がある
- 責任ある仕事を任されると力を発揮する
- ゴールの見えない仕事や停滞にストレスを感じる
- 自分に厳しく、完璧を求めて自分を追い込みやすい

**成長支援**
- 本人と一緒に「少し背伸びすれば届く目標」を決めます（アチーブメントゾーン：高すぎず低すぎない）。目標は本人が決めたものであることが大切です。
- 進み具合が見えるようにします（チェックリスト、段階の区切り）。
- やり遂げたら一緒に振り返り、次の挑戦を本人と決めます。
- 等級の成長マトリクスで、次のステージへの道筋を示します。

**能力開発**
- 始まりと終わりのある取り組みを任せます：新しい施術メニューの導入準備、待ち時間の改善、手順書の改訂など
- 目標達成の技術を教えます：目的 → 目標 → 計画 → 日々の実践（アチーブメントピラミッド）、優先順位のつけ方
- 小さな達成を積み重ねて勢いをつけます（はずみ車）。

**声かけ例**
- 「今期、どんなことを成し遂げたいですか？」
- 「やり遂げましたね。一番効いたのは何だったと思いますか？ 次は何に挑戦しますか？」
- 「結果だけでなく、ここまでの積み重ねが素晴らしかったです」

**避けたい関わり**
- ゴールを示さずに仕事を渡す
- やり遂げたことを当然と見なして何も言わない
- 目標を上から押しつける（本人が決めた目標でないと燃えません）

**注意**
- 自分を追い込みやすい人です。結果だけでなく過程も承認し、休む計画も目標に入れてもらいます。

### 欲求が低い人

**表れ**
- 目標や期限にプレッシャーを感じやすい
- 成果より、日々の過程や人との関係を大切にする
- 目の前の仕事を丁寧に、着実にこなす

**成長支援**
- 大きな目標ではなく、小さな行動目標・習慣目標から始めます（例：「毎回、ホームケアの説明を一言添える」）。
- 目標の意味を、その人の強い欲求の言葉で語ります（愛・所属が強ければ「患者さんや仲間のために」）。
- 「できるようになったこと」を一緒に書き出し、積み上がっている実感をつくります。

**能力開発**
- 日々の業務の正確さ・丁寧さを、強みとして磨きます。
- 振り返りは「何ができたか」から始めます（自己評価シートの「実行」「結実」）。

**声かけ例**
- 「大きな目標でなくて大丈夫です。来月までに『これができたら嬉しい』ことはありますか？」
- 「毎日の丁寧な仕事が、クリニックの信頼をつくっています」

**避けたい関わり**
- 期限や目標で追い込む
- 「向上心がない」と決めつける

## 項目6　承認
意味：認められたい、評価されたい、必要とされたい

### 欲求が強い人

**表れ**
- 認められると大きく伸びる
- フィードバックを求め、評価に敏感
- 頑張りに気づかれないと、急速に意欲が下がる
- 人の目を気にして、評価に一喜一憂しやすい

**成長支援**
- こまめで具体的なポジティブフィードバックを伝えます。結果・行動・存在への承認と感謝を、状況・行動・影響がわかる形で。
- 見えにくい貢献（準備、片付け、フォロー）を見つけて言葉にします。
- 役割を名前で任せます（「〇〇担当」）。
- 認められ方の好みを本人に聞きます（人前か、1対1か）。

**能力開発**
- 人前で発表する機会：院内勉強会、症例や気づきの共有、朝礼でのスピーチ
- 後輩指導（教える役割は、必要とされる実感につながります）
- 資格・検定への挑戦（例：等級の必須の学びにある日本化粧品検定）
- 自分で自分を認める力を育てます：「自分では、どこが良かったと思いますか？」

**声かけ例**
- 「今日の〇〇さんの説明で、患者さんがとても納得されていました。あのたとえが良かったです」
- 「この1か月で、予約対応がとても早く正確になりましたね」
- 「認めてもらえたと感じるのは、人前で言われるときと1対1のとき、どちらですか？」

**避けたい関わり**
- 「いつもありがとう」だけの抽象的な褒め方
- 承認を、人を動かすための道具にする（＝褒美で釣る）
- 承認が特定の人に偏る（えこひいきに見える）

**注意**
- 承認を外にだけ求めると、評価に振り回されて疲れます。自己評価（原則5）で、自分の基準で自分を認める力も育てます。

### 欲求が低い人

**表れ**
- 人の評価をあまり気にせず、マイペース
- 褒められると照れる、反応が薄い
- 自分の基準で仕事をしている

**成長支援**
- 大げさな称賛より、事実を淡々と伝えます。
- 人前で褒めることは控えめにします（居心地が悪い人もいます）。
- 本人の基準や仕事への姿勢を尊重します。

**能力開発**
- 自己評価が先、すり合わせが後の面談が合います（自己評価シートを起点に対話）。

**声かけ例**
- 「〇〇の件、助かりました。おかげで△△がスムーズに進みました」
- 「ご自身では、どう評価していますか？」

**避けたい関わり**
- 大勢の前での表彰を強いる
- 褒めることで動かそうとする

## 項目7　貢献
意味：人の役に立ちたい、力を貸したい、価値を生み出したい

### 欲求が強い人

**表れ**
- 誰かの役に立つことが喜び。患者さんや仲間のために自然に動ける
- 頼まれると断れず、抱え込みやすい
- 自分の仕事が誰の役に立っているか見えないと、むなしさを感じる

**成長支援**
- 仕事の先にいる人を見せます：患者さんからの感謝の声、アンケートや口コミの声を本人に届けます。
- 「ありがとう」を具体的に伝えます。
- 人材成長の三段階の順番を伝えます：「まずは自分を大切にすることが先」（STEP1 3章）。

**能力開発**
- 患者さんを支える仕事：施術後のフォロー、ホームケアの説明、不安への寄り添い
- 新人のサポート、院内の困りごとの解決（業務改善の提案）
- 自分の仕事と理念・ミッション（肌すこやかに、心かろやかに、大切な人生を次のステージへ）とのつながりを言葉にしてもらいます。

**声かけ例**
- 「この前の患者さんが、『〇〇さんの説明で安心できた』と言っていましたよ」
- 「準備してくれていたおかげで、診察がスムーズでした。ありがとうございます」
- 「今抱えている仕事で、手放したいもの、手伝ってほしいものはありますか？」

**避けたい関わり**
- 感謝を伝えない、貢献を当然と見なす
- 断れない優しさに仕事を集中させる（燃え尽きにつながります）

**注意**
- 定期的に抱え込みを確認します。断ることや助けを求めることも、チームへの貢献だと伝えます。

### 欲求が低い人

**表れ**
- 人のためより、自分の仕事や成長に集中する
- 担当範囲をきっちり、割り切って取り組む
- 「誰かのために」という言葉が響きにくい

**成長支援**
- 貢献を押しつけず、本人の強い欲求（達成・学習・成長・自分らしさなど）で動機づけます。
- 担当範囲と任せる裁量を明確にします。
- 自己愛・自己成長の充実を支えることが、結果として他者貢献につながります（STEP1 3章）。

**能力開発**
- 専門性を磨くことが、そのまま患者さんの役に立っているという構造を見せます（技術向上 → 仕上がりの質 → 患者さんの満足）。

**声かけ例**
- 「〇〇さんが技術を磨いてくれることが、そのまま患者さんの満足につながっています」
- 「この担当は、〇〇さんの判断で進めて大丈夫です」

**避けたい関わり**
- 「患者さんのために」を繰り返し、罪悪感で動かす
- 自己犠牲を求める

## 項目8　競争
意味：勝ちたい、負けたくない、一番になりたい

### 欲求が強い人

**表れ**
- 負けず嫌いで、挑戦や比較で燃える
- 自分の位置を知りたがる
- 負けたと感じると、悔しさで意欲が下がったり、対立が生まれたりすることがある

**成長支援**
- 競う相手を、同僚ではなく「昨日の自分」「基準」「外の世界」に向けます。
  - 昨日の自分：等級要件のクリア、できるようになったことの更新
  - 基準：手順書・接遇の基準の完全な実践
  - 外の世界：資格・検定、業界セミナー、「地域で一番信頼されるクリニック」というチームの挑戦
- 個人の数値やランキングはつくりません。チームの挑戦とセットにします。

**能力開発**
- 資格・検定への挑戦、外部セミナーでの学び
- 他院や業界の取り組みを調べ、チームに持ち帰る役割

**声かけ例**
- 「半年前の自分と比べて、何ができるようになりましたか？」
- 「地域で一番安心して来ていただけるクリニックにするには、何が必要だと思いますか？」
- 「次の等級の要件で、最初に取りにいきたいのはどれですか？」

**避けたい関わり**
- 同僚同士の勝ち負けをあおる（チームの所属が崩れます）
- 賞品や報酬で競わせる（＝褒美で釣る）
- 負けたと感じたときに放っておく

**注意**
- 同僚をライバル視して対立しないよう、Win–Win（CDBフィロソフィー⑤）を共通の物差しにします。

### 欲求が低い人

**表れ**
- 争いを好まず、協調的
- 比較されることが苦手
- 人と比べられる場面で萎縮しやすい

**成長支援**
- 他の人と比べません（年次評価の運用原則と同じ）。成長は過去の本人との比較で伝えます。
- チームの中での役割を示し、協力の中で力を発揮してもらいます。

**能力開発**
- 協働型の取り組み：ペア業務、チームでの改善活動

**声かけ例**
- 「3か月前の〇〇さんと比べて、ここが成長しましたね」
- 「チームの中で、〇〇さんのこの役割に助けられています」

**避けたい関わり**
- 「〇〇さんはできているのに」と比較する
- 人と比べる場に引き出す

## 読み方のヒント（力の欲求）

- **4項目のバランスを見る**：同じ「力が強い」でも、達成型（やり遂げたい）、承認型（認められたい）、貢献型（役に立ちたい）、競争型（勝ちたい）で関わり方はまったく違います。
- **承認の注力が欲求を大きく上回る**：評価を気にして頑張りすぎている可能性。自己評価で、自分の基準で認める力を育てます。
- **競争の注力が欲求を大きく上回る**：役割上、負けられない場面を背負っている可能性。チームで分け合えるものを探します。
- **達成・貢献がともに強い人**：頑張り屋で燃え尽きやすい組み合わせです。休むことも計画に入れてもらいます。
- **達成の現実が低い（φ）**：任された範囲が小さい、ゴールが見えない、やり遂げた実感が得にくいことが多い。始まりと終わりのある取り組みを一つ任せます。
