# 欲求別 成長支援ガイド（院長・幹部用）
## STEP2-5　楽しみの欲求（ユーモア／好奇心／学習・成長／創造性）

- 型：項目ごとに、欲求が強い人／低い人それぞれ「表れ・成長支援・能力開発・声かけ例・避けたい関わり」
- 前提：STEP1の7原則。学びは「勤務時間内・実務に直結」を基本とし、勤務外の自己研鑽を当然視しません。

---

## 項目12　ユーモア
意味：人を笑わせたい、楽しませたい、場を盛り上げたい

### 欲求が強い人

**表れ**
- 場を明るくするムードメーカー
- 笑いのある職場が好きで、堅すぎる雰囲気で消耗する
- 患者さんや新人の緊張をほぐすのが上手

**成長支援**
- 明るさを職場の財産として認めます。
- 朝礼やミーティングの始まりで、場をあたためる役割を任せます。
- 笑いが合う場面・合わない場面（TPO）を、責めずに一緒に言葉にします。

**能力開発**
- 場づくりの力をファシリテーションに育てます（ミーティングの進行、新人の受け入れ）。
- 緊張しやすい患者さん（初診の方、お子さん、初めての施術の方）への接遇
- 明るさと誠実さを両立した説明の仕方

**声かけ例**
- 「〇〇さんがいると、待合室の空気がやわらぎますね」
- 「新人さんが緊張しているので、ほぐしてあげてもらえますか？」
- 「この場面は、落ち着いたトーンの方が患者さんに安心してもらえそうです。どう思いますか？」

**避けたい関わり**
- 「ふざけないで」と一律に抑え込む
- 人前でTPOを注意する（伝えるときは1対1で、事実と場面に焦点を当てて）

**注意**
- 笑いが誰かをからかう形にならないよう、場の安全を一緒に守ってもらいます（分かち愛「違いは違いであって、間違いではない」）。

### 欲求が低い人

**表れ**
- まじめで落ち着いている
- 冗談より本題を大切にする
- 盛り上げ役や余興を求められると負担に感じる

**成長支援**
- 落ち着きを強みとして認めます（重い相談、ご不満への対応、説明の多い場面）。
- 盛り上げ役やノリを求めません。

**能力開発**
- 丁寧で誠実な説明、正確な情報提供の力を磨きます。

**声かけ例**
- 「落ち着いた説明で、患者さんが安心されていましたね」

**避けたい関わり**
- 「もっと明るく」「ノリが悪い」と言う
- 余興や盛り上げ役を強いる

## 項目13　好奇心
意味：新しいものに興味がある。未経験のことにも挑戦したい、追求したい

### 欲求が強い人

**表れ**
- 「なぜ？」が多く、新しい知識や情報に敏感
- 調べることが好きで、新しいことに自分から挑戦する
- 興味が持てない作業は後回しになりやすい
- 興味が広がりすぎて、手が回らなくなることがある

**成長支援**
- 「なぜこうするのか」を説明します（理由がわかると動けます）。
- 興味のある分野を深める時間とテーマを、業務の中に用意します。
- テーマと期限を一緒に決め、興味が広がりすぎないよう伴走します。

**能力開発**
- 新しい治療・スキンケア成分・機器の調査担当
- 調べたことを院内勉強会や朝礼で共有（学びの分かち合い）
- 患者さんからよくある質問の答えづくり（AI院長のナレッジ追加など）

**声かけ例**
- 「その疑問、いいですね。調べて、次のミーティングで教えてもらえますか？」
- 「最近、気になっている分野はありますか？」
- 「いくつか気になることがあるなら、今月はどれから深めますか？」

**避けたい関わり**
- 「いいから言われたとおりに」と質問を封じる
- 興味を持ったことを否定する

### 欲求が低い人

**表れ**
- 必要なことを確実にこなす
- 知識を広げるより、確実に実行することを大切にする
- 「調べておいて」と言われると負担に感じる

**成長支援**
- 学ぶ範囲を絞って示します（「これだけ押さえれば大丈夫」）。
- 必要になったときに学べる形にします（チェックリスト、よくある質問集）。

**能力開発**
- 業務に直結する知識を、ピンポイントで身につけます。
- 実務の中で学ぶ（OJT）を中心にします。

**声かけ例**
- 「この業務で必要なのは、この3点だけです。まずはここから」

**避けたい関わり**
- 大量の資料を渡す
- 「どうして興味を持たないの？」と責める

## 項目14　学習・成長
意味：できることを増やしたい。知識が増えること、成長すること、学ぶことが好き

### 欲求が強い人

**表れ**
- スキルアップに意欲的で、研修や資格に前向き
- 成長の実感がないと停滞感を覚え、意欲が下がる
- 学ぶことに夢中になり、実践が追いつかないことがある

**成長支援**
- 等級の成長マトリクスで、成長の道筋と「必須の学び」を示します。
- 定期的に「何ができるようになったか」を一緒に振り返り、成長の実感を言葉にします。
- 学びの機会を途切れさせません（外部研修、セミナー、院内勉強会）。

**能力開発**
- 等級の必須の学び（アチーブメントの講座、日本化粧品検定など）に計画的に挑戦
- 後輩指導（教えることで、学びが深まります）
- 院内勉強会の企画・発表（学びの分かち合い）
- 能力開発の5段階「知る → 分かる → 行う → できる → 分かち合う」を意識し、学んだことを一つ現場で使うことをセットにします。

**声かけ例**
- 「半年前と比べて、何ができるようになったと思いますか？」
- 「次に身につけたいことは何ですか？ そのための計画を一緒に立てましょう」
- 「学んだことの中で、明日から現場で一つ使うとしたら何ですか？」

**避けたい関わり**
- 「まだ早い」で挑戦を止める
- 学んだことを認めない、共有の場を与えない

### 欲求が低い人

**表れ**
- 今の仕事を安定してこなすことに満足している
- 新しい学びを負担に感じ、研修より実務を好む

**成長支援**
- 学ぶこと自体を目的にせず、本人の強い欲求につながる学びに絞ります（例：愛・所属が強ければ「患者さんに喜ばれる説明を一つ覚える」）。
- 必要な学びは勤務時間内の短い勉強会で行います。
- 今の仕事を確実にこなしていることを、きちんと認めます。

**能力開発**
- OJTで、やりながら学ぶ形を中心にします。
- 所属の欲求が強ければ、ペアで学ぶ形にします。

**声かけ例**
- 「新しく覚えるのは、この1つだけです。患者さんの〇〇に役立ちます」
- 「今の仕事を確実にやってくれていることが、何より大事です」

**避けたい関わり**
- 勤務時間外の自己研鑽を当然視する
- 学んだ量で人を評価する

## 項目15　創造性
意味：自分で創り出したい。自分のアイデアを形にしたい（頂点への道テキストでは「独創性」）

### 欲求が強い人

**表れ**
- アイデアが豊富で、工夫や改善が好き
- ゼロから何かを形にすることに喜びを感じる
- 決まりきった作業だけが続くと退屈する
- アイデアが多い分、実行や定着が追いつかないことがある

**成長支援**
- 提案を歓迎する仕組みをつくります（改善提案、まず小さく試す許可）。
- 作ったものが形になる仕事を任せます（院内掲示、患者さん向け資料、発信の企画、動線の改善）。
- アイデアを選ぶ基準を共有します（理念・患者さんにとっての価値・コスト）。

**能力開発**
- 企画力：業務改善の取り組み、院内イベントの企画
- 表現の力：患者さん向け資料や発信のデザイン
- アイデアを実行計画に落とす力（目的 → 目標 → 計画）
- 定着は、安全・安定の欲求が強い人と組んで進めます。

**声かけ例**
- 「このアイデア、面白いですね。まず小さく試してみましょう」
- 「待ち時間をもっと快適にするとしたら、何ができると思いますか？」
- 「このアイデアは、患者さんにとってどんな価値がありますか？」

**避けたい関わり**
- アイデアを頭ごなしに却下する
- 「余計なことはしないで」と言う

### 欲求が低い人

**表れ**
- 決まったやり方を正確に再現するのが得意
- ゼロからの企画やアイデア出しを負担に感じる

**成長支援**
- 白紙からの企画を求めません。
- 既にある型を磨く役割、アイデアを形にする実行役を任せます。

**能力開発**
- 「ゼロから」ではなく「今あるものを一つ良くする」小さな改善を経験します。

**声かけ例**
- 「この手順で、やりにくいところを一つだけ教えてください」
- 「このアイデアを形にする実行役として、力を貸してもらえますか？」

**避けたい関わり**
- 白紙で「何かアイデアを出して」と求める
- アイデアを出さないことを否定的に評価する

## 読み方のヒント（楽しみの欲求）

- **学習・成長の現実が低い（φ）**：成長の実感が持てていない状態。離職の芽になりやすいため、優先して聴きます。「最近、できるようになったこと」を一緒に書き出すことから始めます。
- **好奇心・創造性の注力が欲求を大きく上回る**：新しいことを任され続けて疲れている可能性。定着や実行を他の人に渡すことも選択肢です。
- **楽しみ全体の現実が低い**：義務感だけで働いている状態の可能性。楽しみの欲求は、本来「義務感にとらわれずに主体的に」満たされるものです。仕事の中で「自分から選んでやっていること」を一緒に探します。
- **好奇心・学習・成長が強く、変化も強い人**：新しいことに次々向かうタイプ。学んだことを一つ現場で使い切る（能力開発の5段階の「できる」「分かち合う」まで）を伴走します。
