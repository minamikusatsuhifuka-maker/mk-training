# 欲求別 成長支援ガイド（院長・幹部用）
## STEP2-2　愛・所属の欲求（愛／所属）

- 型：項目ごとに、欲求が強い人／低い人それぞれ「表れ・成長支援・能力開発・声かけ例・避けたい関わり」
- 前提：STEP1の7原則と、5章「女性スタッフの職場での留意点」（特に5「少人数の職場では、関係のずれが所属を一気に下げる」）
- 関わりの目安：愛は「一人ひとりとの関係」、所属は「チームとの関係」

---

## 項目3　愛
意味：人を大切にし、自分も大切にされたい。愛し愛されたい、人が好き

### 欲求が強い人

**表れ**
- 人が好きで、相手の気持ちに敏感。思いやりや気配りが細やか
- 患者さんへの共感力が高く、寄り添う対応ができる
- 冷たい対応、無関心、関係のこじれで大きく消耗する
- 大切にされていないと感じると、意欲が急に下がる
- 頼まれると断れず、抱え込みやすい

**成長支援**
- 1対1の関係の質を大切にします。名前で呼ぶ、話を最後まで聴く、小さな変化に気づいて言葉にする。
- 1on1では、仕事以外の話も本人が話したい範囲で受けとめます。
- 成果だけでなく、存在そのものへの承認と感謝を伝えます。
- 関係がこじれたときは早めに間に入り、事実と気持ちを分けて聴きます。

**能力開発**
- 共感力を専門性に育てます：傾聴・カウンセリングの技術、不安の強い患者さん（初めての美容相談、長く悩んでいる肌の症状など）への対応、ご不満があった後の関係修復
- 新人のメンター役を任せます。
- 自分の共感の関わりを言葉にして、後輩に伝えられるようにします（感覚をスキルに）。

**声かけ例**
- 「〇〇さんが声をかけたあと、患者さんの表情がやわらいでいましたね」
- 「最近どうですか？ 話したいことがあれば、いつでも聴きます」
- 「いつも周りを気にかけてくれてありがとうございます。〇〇さん自身は、無理していませんか？」

**避けたい関わり**
- 忙しさを理由に話を遮る、後回しにする
- 人前での叱責
- 無視する、反応しない（関係が切れたと強く感じる）
- 優しさや断れなさに甘えて、仕事を集中させる

### 欲求が低い人

**表れ**
- 感情に流されず、冷静で公平
- 深い付き合いを求めず、仕事は仕事と割り切れる
- 親しげな関わりや感情の話を負担に感じることがある
- 説明は正確でも、そっけなく見られることがある

**成長支援**
- 距離感を尊重します（私生活に踏み込まない、親睦は任意）。
- 仕事上の信頼関係は丁寧に築きます。約束を守る、事実で話す。
- 冷静さ・公平さが活きる役割を任せます（会計・レセプト、トラブル時の対応、データ管理）。

**能力開発**
- 共感の表現を、感情ではなく「型（スキル）」として学びます：相づち、復唱、気持ちを言葉にする（「ご不安でしたよね」）。
- 正確さに一言の気遣いを添えて、説明の質を上げます。

**声かけ例**
- 「トラブルのとき、〇〇さんが冷静でいてくれると助かります」
- 「説明がとても正確ですね。最初に『ご不安でしたよね』と一言添えると、さらに伝わりますよ」

**避けたい関わり**
- 「もっと心を開いて」「冷たい」と性格を指摘する
- 親睦やプライベートの共有を求める

## 項目4　所属
意味：仲間と一緒にいたい。集団の一員として、みんなで何かをするのが好き

### 欲求が強い人

**表れ**
- チームの和を大切にし、協力的
- 朝礼・ミーティング・行事に前向きで、チームのために動ける
- 輪や情報から外れることに強い不安を感じる
- チームの不和で大きく消耗する
- 周りに合わせすぎて、自分の意見を飲み込むことがある

**成長支援**
- チームの中での役割を明確にします（「〇〇担当」）。
- 情報共有の場に必ず入れ、全員に同時に伝えます。
- チームの成果を一緒に喜ぶ場をつくります。
- 新しい人を迎え入れる文化づくりの担い手になってもらいます。

**能力開発**
- チーム運営のスキル：ミーティングの進行、新人の受け入れ・OJT、職種間（看護師⇔受付・クラーク）の連携調整、朝礼での理念の共有
- 意見の違いを恐れず伝える練習をします（身に付けたい7つの習慣「意見の違いについて交渉する」）。チームが成熟する過程では、ぶつかり合う時期を越えることが必要です。

**声かけ例**
- 「〇〇さんがいると、チームがまとまりますね」
- 「今度の新人さんの受け入れ、チームの中心になってもらえますか？」
- 「〇〇さんの意見も聞かせてください。みんなと違っていても大丈夫です」

**避けたい関わり**
- 情報を後回しにする、一部の人にだけ伝える
- 会議や輪から外す
- 「仲良しごっこ」と揶揄する
- チームの前で叱責する

**注意**
- 所属の欲求が強い人が集まると、内輪化や同調圧力が生まれることがあります。分かち愛の「違いは違いであって、間違いではない」を合言葉に、意見の違いと新しい人を歓迎する文化を一緒につくります。

### 欲求が低い人

**表れ**
- 一人で黙々と集中でき、独立心がある
- 集団行動や行事、付き合いを負担に感じる
- チームの空気に流されず、自分の判断で動ける

**成長支援**
- 行事・親睦は任意にします（参加しないことで評価は変わりません）。
- 一人で完結し、責任を持てる担当を任せます（在庫管理、レセプト、マニュアル作成など）。
- チームとの接点は「仕事の連携」に絞り、仕組みにします。

**能力開発**
- 連携（報連相・申し送り）は「チームの基準」として形をそろえます（申し送りの書式など）。
- 専門性を深める道（スペシャリストとしての成長）を示します。
- 流されない視点を、チームに還元してもらいます（業務の見直し、マニュアルの点検）。

**声かけ例**
- 「一人で任せられる安心感があります」
- 「チームで決めたこの申し送りの形だけは、一緒に守ってください。やり方はやりやすいように工夫して大丈夫です」
- 「外から見て、チームの進め方で気づくことはありますか？」

**避けたい関わり**
- 「協調性がない」と評価する
- 全員参加を強いる、行事に参加しないことを咎める

## 読み方のヒント（愛・所属の欲求）

- **愛の現実が低い（φ）**：特定の人との関係のずれが背景にあることが多い。いきなり「誰との関係ですか」と聞かず、「最近、職場で話しやすい人はいますか？」と穏やかに入ります。関係の話は、事実と気持ちを分けて聴きます。
- **所属の現実が低い**：情報の届き方や「輪の外にいる感覚」が背景にあることが多い。情報共有の仕組みを見直します。入職直後・異動直後・休み明けに起こりやすい時期です。
- **愛・所属の注力が欲求を大きく上回る**：周りに合わせることや気を遣うことに疲れている可能性。「断ってもいい」「自分を大切にすることが先」（人材成長の三段階）を伝えます。
- **少人数の職場**：一人の関係のずれがチーム全体に広がりやすいため、早めに気づき、早めに聴きます（STEP1 5章）。
