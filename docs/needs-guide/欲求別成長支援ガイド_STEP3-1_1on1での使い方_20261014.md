# 欲求別 成長支援ガイド（院長・幹部用）
## STEP3-1　1on1・可能性ノートでの使い方

- 前提：STEP1の7原則（特に原則5 自己評価、原則7 評価に使わない）、STEP2の15項目
- 1on1は1回10〜15分。**扱う欲求は1回に1つ**に絞ります。

---

## 1. 1年の流れ

| 時期 | 場 | 欲求の視点での使い方 |
|---|---|---|
| 診断後すぐ | 結果を共有する1on1 | 本人が結果をどう感じたかを聴く。強い欲求の上位3つとφを確認。共有範囲の同意 |
| 毎回 | 通常の1on1 | 1つの欲求（φ、または本人が選んだテーマ）を扱う |
| 夏 | 半期面談 | 欲求の満たされ方の変化を一緒に振り返る（評価には使わない） |
| 冬 | 年次対話 | 来期のWANTSを、強い欲求の言葉で言語化する |
| 半年〜1年ごと／ライフイベント・役割変更時 | 再診断 | 注力と現実の変化を見る |

---

## 2. 結果を共有する1on1（初回）

15分で全部は扱いません。**強い欲求の上位3つとφ**だけに絞ります。

1. **本人が先に語る**
   「結果を見て、どう感じましたか？」「当たっていると思うところ、違うと思うところはありますか？」
2. **強い欲求の満たされ方を聴く**（上質世界の具体化）
   「〇〇の欲求が強く出ていますね。仕事の中で、どんなときに満たされていると感じますか？」
3. **φを聴く**
   「〇〇は、欲求に比べて今は満たされにくいようです。思い当たることはありますか？」（話したくなければ次回で大丈夫、と添える）
4. **共有範囲の同意**
   「この結果を、どこまで共有してよいですか？（院長のみ／担当の幹部まで／mk-trainingで公開）」
5. **次の1on1で扱うテーマを本人が選ぶ**

---

## 3. 通常の1on1（10〜15分）の進め方

1つの欲求を、RWDEPCで扱います。

| 時間 | 段階 | 関わる側がすること | 問いかけ例 |
|---|---|---|---|
| 0〜2分 | R 関係づくり | 近況を聴く。ポジティブフィードバック・感謝から始める | 「最近どうですか？」「先日の〇〇、助かりました」 |
| 2〜5分 | W 願望 | テーマの欲求について、どんな状態が「満たされている」かを聴く | 「〇〇について、どうなっていたら嬉しいですか？」 |
| 5〜9分 | D 行動／E 評価 | 今していることと、その効果を本人に評価してもらう | 「そのために、今何をしていますか？」「それは効果的ですか？」 |
| 9〜13分 | P 計画／C 約束 | 次の小さな一歩を、本人が一つ決める | 「次に、何をやってみますか？」「いつから始めますか？」 |
| 13〜15分 | 記録の確認 | 可能性ノートに何を残すかを、本人と確認する | 「今日のことは、この内容で残してよいですか？」 |

**ポイント**
- 話す割合は、本人7：関わる側3を目安にします。
- 提案は、本人の案を聴いてから。提案するときも「こういう方法もありますが、どう思いますか？」と選択肢として渡します。
- 決めた一歩は、次回の1on1の冒頭で一緒に振り返ります。

## 4. 欲求別「満たされ方を聴く」最初の一言

テーマの欲求が決まったら、この一言から入ります（STEP2の声かけ例とあわせて使います）。

| 項目 | 最初の一言 |
|---|---|
| 安全・安定 | 「仕事の中で、今、見通しが立たなくて気になっていることはありますか？」 |
| 健康 | 「最近の調子はどうですか？ 仕事の進め方で調整できることはありますか？」 |
| 愛 | 「最近、職場で話しやすい人、気持ちが通じたと感じた場面はありますか？」 |
| 所属 | 「チームの中で、自分の居場所や役割を感じるのはどんなときですか？」 |
| 達成 | 「今、やり遂げたいと思っていることは何ですか？」 |
| 承認 | 「最近、認めてもらえたと感じたのはどんなときですか？」 |
| 貢献 | 「最近、誰かの役に立てたと感じた場面はありますか？」 |
| 競争 | 「半年前の自分と比べて、超えられたと思うことは何ですか？」 |
| 解放 | 「今、何に一番縛られている感じがしますか？」 |
| 変化 | 「今の仕事に、どんな新しさがあると嬉しいですか？」 |
| 自分らしさ | 「仕事の中で、一番大切にしたいことは何ですか？」 |
| ユーモア | 「職場で笑顔になれた場面はありましたか？」 |
| 好奇心 | 「最近、気になっていることや、知りたいことはありますか？」 |
| 学習・成長 | 「最近、できるようになったことは何ですか？」 |
| 創造性 | 「もっとこうしたら良くなるのに、と思うことはありますか？」 |

## 5. 1on1の冒頭で口頭で使う問い

事前アンケートには入れず、1on1の冒頭で必要に応じて口頭で使います。

1. 最近、仕事の中で「満たされている」と感じた場面はありますか？
2. 最近、少し満たされていないと感じることはありますか？（話せる範囲で）
3. 今日話したいテーマはありますか？（例：働き方、人間関係、学び、役割、やりたいこと）

- 欲求の名前（「承認欲求」など）は、問いに使いません。本人の言葉で話してもらいます。

---

## 6. 可能性ノートへの記録のルール

欲求プロフィールは内面の情報です。記録は次の範囲にとどめます。

**記録すること**
- 本人が話したこと（本人の言葉で）
- 合意した次の一歩と、その振り返り
- ポジティブフィードバック（本人も見られます）
- ギャップフィードバックの「事実・すり合わせ・改善計画」（本人も見られます）

**記録しないこと**
- 関わる側の推測やラベル（例：「承認欲求が強いから○○しがち」）
- 体調・家庭の事情で、本人が記録を望まないこと
- 欲求の強弱を、評価や処遇の根拠として扱う記述

**1on1の書き起こしをAIでまとめる場合も同じです。** まとめに欲求のラベルや性格の推測が入っていたら、記録欄に移す前に削ります。

---

## 7. ギャップフィードバックを欲求の言葉で伝える

ギャップフィードバックの3ステップは変えません。変えるのは「意味の語り方」だけです（原則6）。

1. **事実の把握**：状況・行動・影響を事実で伝え、主観は「私は〜と感じました」で伝える
2. **問題点のすり合わせ**：人ではなく「事」に焦点を当てる
3. **改善計画**：本人が考え、本人が決める

**例：申し送りの漏れがあったとき**
- 事実：「昨日の午後、〇〇の申し送りが記録になく、△△さんが患者さんに確認し直すことになりました」
- 意味の語り方（相手の強い欲求で）
  - 所属が強い人に →「チームみんなが安心して動けるように、一緒に整えたいです」
  - 貢献が強い人に →「患者さんをお待たせしないために、大切なところです」
  - 解放が強い人に →「やり方はお任せします。漏れが起きない形を考えてもらえますか？」
- 改善計画：「どうしたら漏れなくできそうですか？」

## 8. よくある場面

**本人があまり話さない**
- 沈黙を急いで埋めず、少し待ちます。
- 選択肢を示します（「働き方、人間関係、学びの中で、どれが一番話しやすいですか？」）。
- 「今日は話さなくても大丈夫です」と伝え、次回につなげます。話さないことも本人の選択として尊重します。

**疲れが見える（注力が欲求を大きく上回る項目がある）**
- その日は計画を立てず、聴くことを中心にします。
- 「今抱えているもので、手放したいもの、手伝ってほしいものはありますか？」

**ライフイベントの時期**
- 生存と自由の満たされ方が大きく動きます。制度や働き方の選択肢を情報として伝え、本人が選びます（STEP1 5章）。

**φが関わる側との関係にありそうなとき**
- 防衛せず、まず聴きます。「私の関わり方で、変えたほうがいいことはありますか？」（インサイドアウト）

---

## 9. 1on1のあとの自己点検

- 致命的な7つの習慣を使わなかったか
- 本人が話す時間が、自分より長かったか
- 次の一歩を、本人が決めたか
- 欲求を評価やラベルとして使わなかったか
- 記録の内容を、本人と確認したか
