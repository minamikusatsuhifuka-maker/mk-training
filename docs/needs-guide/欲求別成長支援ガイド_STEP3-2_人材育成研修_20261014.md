# 欲求別 成長支援ガイド（院長・幹部用）
## STEP3-2　人材育成研修（欲求の視点で関わる力を磨く）

- 対象：院長が指定した幹部（mk-training管理画面の「人材育成研修」で指定）
- 講師：はじめは院長。2巡目からは幹部が交代で進行します（学びの分かち合い）
- 構成：全3回・各60分（月1回の院内勉強会の枠でも実施できます）
- 教材：STEP1（土台）、STEP2（15項目）、STEP3-1（1on1での使い方）
- 流れ：能力開発の5段階「知る → 分かる → 行う → できる → 分かち合う」に沿って進めます

---

## 研修の約束（毎回の冒頭で確認）

- ここで話した自分の欲求や体験は、本人の同意なく外に出しません。
- 自分の診断結果を話すかどうかは、自分で選びます（話さなくても大丈夫です）。
- 実際のスタッフの名前や結果は、研修の題材にしません。ケースはすべて架空です。
- 誰かを評価する場ではなく、自分の関わり方を磨く場です。

---

## 第1回　土台：まず自分を知る（60分）

**ねらい**：関わる側の欲求は、そのまま関わり方の癖になります。他者を支援する前に、自分の欲求と癖を知ります（インサイドアウト）。

| 時間 | 内容 |
|---|---|
| 0〜10分 | 研修の約束、ねらいの共有 |
| 10〜25分 | 読み合わせ：STEP1の2章「7原則」と4章「結果の読み方」 |
| 25〜45分 | ワーク1：自分の欲求と関わり方の癖 |
| 45〜55分 | ペアで共有（話せる範囲で） |
| 55〜60分 | 一人ひとつ、明日から変える関わりを宣言 |

**ワーク1：自分の欲求と関わり方の癖**（個人で記入）
1. 自分の強い欲求の上位3つは何ですか？
2. その欲求が、スタッフへの関わり方にどう表れていそうですか？
3. 自分の満たし方を、相手に当てはめてしまっていることはありませんか？

**考える手がかり（例）**
- 達成が強い → 相手にも高い目標や期限を求めがち
- 承認が強い → 自分が認められたい場面で、相手の承認を後回しにしがち
- 解放が強い → 任せすぎて、指示が欲しい人を迷わせがち
- 安全・安定が強い → 新しい提案を慎重さで止めがち
- 所属が強い → 一人で集中したい人を、輪に入れようとしがち
- 変化が強い → 安定を好む人に、変化を急がせがち

**まとめの一言**：人間関係の問題は、自分の欲求の満たし方を他人に当てはめるところから生まれます。

## 第2回　15項目と言葉：伝え方を磨く（60分）

**ねらい**：同じ基準を、相手の強い欲求の言葉で語れるようになります（原則6）。致命的な7つの習慣を、身に付けたい7つの習慣に言い換えられるようになります。

| 時間 | 内容 |
|---|---|
| 0〜5分 | 前回の宣言の振り返り（できたこと） |
| 5〜25分 | 読み合わせ：STEP2を5つの欲求で分担し、各自が「自分の担当の欲求で一番大切だと思ったこと」を1分で共有 |
| 25〜40分 | ワーク2：言い換え |
| 40〜55分 | ワーク3：同じ基準を3つの言葉で |
| 55〜60分 | 明日から使う言葉を一つ決める |

**ワーク2：言い換え**（致命的な7つの習慣 → 身に付けたい7つの習慣）

| 言ってしまいがちな言葉 | 言い換え例 |
|---|---|
| 「なんでいつも確認しないの？」（責める） | 「昨日の〇〇、確認の手順が抜けていました。どうしたら抜けずにできそうですか？」 |
| 「みんな頑張ってるんだから」（文句・比較） | 「今、抱えているもので大変なことはありますか？」 |
| 「このままだと評価に響きますよ」（脅す） | 「次の等級に向けて、ここを一緒に伸ばしていきたいです」 |
| 「〇〇さんはできているのに」（批判・比較） | 「3か月前と比べて、ここは成長しましたね。次はここに挑戦してみませんか？」 |
| 「ちゃんとやったら〇〇してあげる」（褒美で釣る） | 「これができると、患者さんにとってどんな良いことがあると思いますか？」 |
| 「何度言ったらわかるの」（ガミガミ言う） | 「私の伝え方が分かりにくかったかもしれません。どこが分かりにくかったですか？」 |

※まず自分で言い換えを考えてから、例を見ます。

**ワーク3：同じ基準を3つの言葉で**
お題：「施術室の片付けと消毒を、次の患者さんの前に必ず終える」
次の3人に、それぞれの強い欲求の言葉で、この基準の意味を伝えてください。
- Aさん：所属が強い
- Bさん：学習・成長が強い
- Cさん：解放が強い

回答例
- Aさん：「チーム全員で守っている約束です。〇〇さんがいるとチームが安心して回ります」
- Bさん：「感染対策はプロとしての基本の技術です。手順の理由も一緒に確認しましょう」
- Cさん：「必ず守る基準はここだけです。順番や段取りは、やりやすいように工夫してください」

## 第3回　1on1ロールプレイ（60分）

**ねらい**：10〜15分の1on1を、RWDEPCで1つの欲求に絞って進められるようになります（STEP3-1）。

| 時間 | 内容 |
|---|---|
| 0〜10分 | STEP3-1の3章「通常の1on1の進め方」の確認 |
| 10〜50分 | ロールプレイ（3人組 × 交代で3回、1回12分＋振り返り） |
| 50〜60分 | 全体の振り返りと、次の実際の1on1で試すことを一つ決める |

**3人組の役割**
- 上司役：1on1を進める
- スタッフ役：ケースカードの人物になりきる
- 観察役：観察シートに記録し、振り返りで伝える

**ケースカード（すべて架空）**

| ケース | 人物（架空） | 強い欲求 | φ（満たされていない） | 状況 |
|---|---|---|---|---|
| A | 入職2年目・医療事務 | 所属・愛 | 承認 | 頑張っているのに気づかれていないと感じている |
| B | 入職5年目・看護師 | 達成・学習・成長 | 解放 | 新しい施術の立ち上げを任されてきたが、細かい確認が多く息苦しい |
| C | 入職1年目・医療事務 | 安全・安定 | 安全・安定 | 来月の業務変更に不安があるが、言い出せない |
| D | 入職3年目・看護師 | 自分らしさ | 愛 | 1on1であまり話さない。周りに合わせすぎて疲れている様子 |

**観察シート**（観察役が記入）
- 本人が話す時間が、上司役より長かったか
- 扱う欲求を1つに絞れていたか
- 本人の言葉で「満たされている状態」を聴けていたか
- 「それは効果的ですか？」で、本人に評価してもらえていたか
- 次の一歩を、本人が決めたか
- 致命的な7つの習慣を使っていなかったか
- 良かった関わりを一つ、具体的に

## 研修のあとに（分かち合い）

- 次の実際の1on1で試したことと気づきを、翌月の院内勉強会で一人1分ずつ共有します。
- 2巡目からは、幹部が交代で進行役を務めます（教えることで、学びが深まります）。
- 研修で使ったワークや言い換えの例は、気づいたものを追加して育てていきます。
