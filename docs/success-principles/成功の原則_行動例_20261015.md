# 成功の原則×日々の行動例と考え方の例

- 対象の教え：成功の八原則／成功の10の障害／成功の10の原則
- 行動例と考え方の例は「選ぶもの」で、「守らせるもの」ではありません。自分で1つ選び、自分でふり返ります。評価には使いません。

---

## 0. 土台　事実と解釈

### 成長とは、価値観の肯定的変化である
- 事実は一つ、解釈は無数。私たちが生きている現実は、事実そのものではなく、事実をどう解釈したかでつくられています。
- 問題そのものより、問題をどう捉えるかが、次の行動を決めます。
- どんな出来事にも、肯定的な意味や意義を見いだせるようになるほど、選べる行動が増え、人生の可能性が広がります。
- 解釈は、生まれつき決まっているものではありません。練習して、選べるようになるものです。

### 肯定的な解釈とは
- 気持ちを無理に押し込めることではありません。つらい、悔しいと感じるのは自然なことです。まず自分の気持ちを受けとめ、そのうえで「この出来事を、どう意味づけるか」を自分で選びます。
- 問題を見ないふりをすることでもありません。安全や患者さんに関わることは、すぐに報告・相談します。そのうえで、「ここから何を学び、次にどうするか」に目を向けます。
- 相手に求めるものではありません。「前向きに考えて」と人に言うのではなく、自分が選ぶものです。

### 解釈を選ぶ4つのステップ
1. **事実を書く**：何が起きたか（見たこと・聞いたこと）
2. **気持ちを受けとめる**：自分は今、どう感じているか
3. **意味を問う**：「この出来事は、自分に何を教えてくれているだろう？」「ここから何を学べるだろう？」
4. **行動を選ぶ**：「では、次に何をしよう？」

### 職場でよくある場面と、成長につながる解釈の例
| 場面（事実） | ついしてしまう解釈 | 成長につながる解釈 |
|---|---|---|
| 患者さんからご不満の声をいただいた | 私は向いていない | 患者さんが本当に求めていることを知る機会をいただいた |
| 自分のミスで、仲間に確認し直してもらった | 迷惑をかけてしまった、もうだめだ | 仕組みを見直すきっかけになった。同じことが起きない方法を考えよう |
| 急に業務の手順が変わった | また振り回される | 新しいやり方を身につけるチャンス。変化に強くなれる |
| とても忙しい一日だった | 疲れただけの一日 | これだけの患者さんの役に立てた一日だった |
| 先輩から改善点を伝えられた | 責められた、嫌われている | 期待してくれているから伝えてくれた。成長の情報をもらえた |
| 仲間と意見が違った | 分かってもらえない | 違う見方を知れた。違いは違いであって、間違いではない |
| 初めての業務を任された | できなかったらどうしよう | 任せてもらえるだけの信頼がある。できるようになる途中を楽しもう |
| 練習してもなかなか上達しない | 才能がない | 力は見えないところで積み上がっている。続けた分だけ必ず力になる |
| 後輩がなかなか覚えられない | 教えても無駄 | 自分の伝え方を磨く機会。後輩に合う教え方を一緒に探そう |
| 頑張ったのに気づいてもらえなかった | 頑張っても意味がない | 自分がやり切ったことは、確かな力として自分に残っている |
| 休みの希望が通らなかった | 大切にされていない | 今回はチームを支える番。次はどうすれば希望が通りやすいか相談しよう |
| 予定どおりに進まなかった | 失敗した | うまくいかない方法が一つ分かった。次の一手が見えた |

## 1. 成功の八原則 × 行動例・考え方

### 一、明確なビジョン（願望）と目標設定
意味：なりたい姿をはっきりさせ、具体的で肯定的な目標を立てる
- 朝、今日いちばん大切にしたいことを1つ決めて、メモに書く
- 半年後に「できるようになっていたい」ことを1つ言葉にする
- 目標を「〜しない」ではなく「〜する」の形で書く
- 考え方：「目標なんて立てても続かない」→「小さな目標でも、決めた瞬間から毎日の意味が変わる」
- 考え方：「今の自分には無理」→「今はできなくても、なりたい姿を描くことが成長の始まり」
- 1on1の問い：「半年後、どんな自分になっていたら嬉しいですか？」

### 二、コミットメント（本気）
意味：決めたことを、やり切るために必要なことは何でもする
- 決めたことを、いつ・何をするかまでスケジュールに入れる
- 「やってみます」ではなく「〇日までにやります」と伝える
- 迷ったとき、決めた目的に立ち返って選ぶ
- 考え方：「できたらやろう」→「やると決めたから、できる方法を探す」
- 考え方：「大変だからやめておこう」→「大変なことほど、やり切ったときに大きな自信になる」
- 1on1の問い：「それを実現するために、何なら必ずできそうですか？」

### 三、冒険
意味：慣れた範囲から一歩踏み出し、思い込みから自由になる
- 初めての業務を、自分から「やってみたいです」と手を挙げる
- 勉強会や朝礼で、1回ひとこと発言してみる
- 「私には無理」と思ったとき、「どうしたらできるか」と言い換えてみる
- 考え方：「失敗したら恥ずかしい」→「挑戦した人だけが、失敗から学べる」
- 考え方：「私はこういう性格だから」→「それは今までの自分。これからの自分は選べる」
- 1on1の問い：「今、少しだけ挑戦してみたいことはありますか？」

### 四、パートナーシップ
意味：相手への援助・貢献から関わる
- 忙しそうな仲間に「何か手伝えることはありますか？」と声をかける
- 自分の仕事が終わったら、次の人が動きやすいように準備しておく
- 仲間の目標を知り、それを応援する
- 考え方：「自分の仕事だけで精一杯」→「仲間の成功は自分の成功。助け合うほど、チームも自分も楽になる」
- 考え方：「あの人とは合わない」→「違うからこそ、自分にない力を持っている」
- 1on1の問い：「最近、誰かの力になれたと感じたことはありますか？」

### 五、正直
意味：素直に見て、素直に伝える。自分にも相手にも誠実に向き合う
- ミスやヒヤリハットは、気づいたその場で報告する
- わからないことは、わかったふりをせずに質問する
- 患者さんに、できること・できないことを正直に伝える
- 考え方：「ミスを言ったら評価が下がる」→「正直に伝えることが、患者さんと仲間を守り、信頼を育てる」
- 考え方：「質問したら恥ずかしい」→「分からないと言える人が、一番早く成長する」
- 1on1の問い：「最近、言いにくかったけど伝えてよかったことはありますか？」

### 六、シェアする
意味：学びや気づきを分かち合い、表現する
- 学んだこと・うまくいった工夫を、朝礼や終礼で1つ共有する
- 患者さんからいただいた感謝の声を、チームに伝える
- 失敗から学んだことも、次の人のために共有する
- 考え方：「こんな小さなこと、言うほどでもない」→「小さな気づきが、誰かの大きな助けになる」
- 考え方：「失敗は隠したい」→「自分の失敗は、仲間が同じつまずきをしないための贈り物になる」
- 1on1の問い：「最近の気づきで、チームに伝えたいことはありますか？」

### 七、責任（自分が源）
意味：「自分が創り出している」という意識で行動する
- うまくいかないとき、「自分にできることは何だろう」と考える
- 誰かのせいにしたくなったとき、まず自分の関わりを振り返る
- 気づいた問題は、改善案とセットで伝える
- 考え方：「〇〇さんのせいで」→「この状況で、自分にできることは何だろう」
- 考え方：「環境が悪いから仕方ない」→「環境は変えられなくても、自分の受け止め方と行動は選べる」
- 1on1の問い：「その状況で、自分にできることは何だと思いますか？」

### 八、凡事徹底
意味：当たり前のことを、特別熱心に、徹底的に行う
- あいさつ・笑顔・名前を呼ぶ接遇を、毎回ていねいに行う
- 使った場所は、次の人のために元より美しく整える
- 確認・申し送りを、忙しいときこそ省かない
- 考え方：「こんな単純なこと、誰でもできる」→「誰でもできることを、誰よりも続けることが一流の土台」
- 考え方：「毎日同じことの繰り返し」→「同じことを、昨日より少していねいにできる自分になっていく」
- 1on1の問い：「当たり前だけど、毎日ていねいに続けていることは何ですか？」

## 2. 成功の10の障害 × つまずきのサインと乗り越える行動・考え方

※「障害」は人の欠点ではなく、誰にでも起こるつまずきやすい傾向です。本人が自分で気づくために使います。

### 1. セルフコントロールができない（時間・健康・意識の管理）
- サイン：やるべきことが後回しになる／疲れが抜けない／気分で仕事の質が変わる
- 乗り越える行動：その日の優先順位を3つ決めてから始める／休憩をきちんと取る／気持ちが乱れたら一呼吸おく
- 考え方：「気分が乗らないからできない」→「行動を変えると、気分はあとからついてくる」
- 問い：「最近、自分でうまく整えられていると感じることは何ですか？」

### 2. 自己概念が低い
- サイン：「私なんて」「どうせ」と口にする／褒められても受け取れない
- 乗り越える行動：その日できたことを1つ書く（勝利リスト）／褒められたら「ありがとうございます」と受け取る
- 考え方：「私には価値がない」→「私には価値がある。できていることに目を向けると、それが見えてくる」
- 問い：「最近、自分をほめてあげたいことは何ですか？」

### 3. 欲求充足の方法がわかっていない（快楽と幸福の混同）
- サイン：一時的な気晴らしに頼る／満たされない感じが続く
- 乗り越える行動：「本当はどうなりたいか」を考え、長く続く満たし方を1つ選ぶ（欲求別成長支援ガイドも参照）
- 考え方：「今が楽ならそれでいい」→「長く続く幸せは、自分と周りを大切にする選択から生まれる」
- 問い：「どんなときに、本当に満たされていると感じますか？」

### 4. 意思決定能力の不足
- サイン：決められずに先延ばしにする／人の意見で何度も変わる
- 乗り越える行動：判断の基準（患者さんにとって何が一番よいか）に立ち返って決める／決める期限を自分で決める
- 考え方：「間違えたらどうしよう」→「決めて動けば、うまくいかなくても修正できる。決めないことが一番進まない」
- 問い：「迷ったとき、何を基準に選びたいですか？」

### 5. 問題解決能力の不足（事実と解釈の混同）
- サイン：問題を大きく感じて動けない／「〇〇さんが悪い」で止まる
- 乗り越える行動：起きたこと（事実）と、自分の受け止め（解釈）を分けて書く／次の一手を1つ決める
- 考え方：「大変な問題が起きた」→「問題は、よりよくなるための入り口。事実を分けて見れば、できることが見えてくる」
- 問い：「起きた事実は何で、どう受け止めていますか？」

### 6. パワーパートナーがいない
- サイン：一人で抱え込む／助けを求められない
- 乗り越える行動：困ったら早めに相談する／自分から先に仲間を助ける
- 考え方：「頼ったら迷惑」→「頼ることは、相手に力を発揮してもらう機会にもなる」
- 問い：「困ったとき、相談できる人は誰ですか？」

### 7. 言い訳の癖
- サイン：「忙しかったので」「〜だから仕方ない」が多い
- 乗り越える行動：理由の前に「次はこうします」を伝える
- 考え方：「できなかった理由がある」→「理由を探すより、次にできる方法を探すほうが自分のためになる」
- 問い：「次に同じ場面があったら、どうしたいですか？」

### 8. 勉強不足
- サイン：わからないことをそのままにする／同じ質問を繰り返す
- 乗り越える行動：わからなかったことをメモし、その週のうちに調べる／AI院長やマニュアルで確かめる
- 考え方：「知らないことが恥ずかしい」→「知らないと気づけたことが、学びのスタート」
- 問い：「今、一番知りたいこと・身につけたいことは何ですか？」

### 9. エネルギー不足
- サイン：意欲がわかない／疲れやすい
- 乗り越える行動：自分のエネルギーが湧く場面を知り、仕事の中に取り入れる／休むときはしっかり休む
- 考え方：「やる気が出ない自分はだめ」→「エネルギーが湧く場面を知ることも、自分を大切にする一歩」
- 問い：「どんなときに、エネルギーが湧いてきますか？」
- ※体調の深掘りはしません。業務の調整で支えられることを聴きます。

### 10. 怠惰・ルーズ
- サイン：時間・期限・片付けが守れない日が続く
- 乗り越える行動：5分前行動／期限を自分の予定に入れる／終わったらすぐ片付ける
- 考え方：「少しくらい遅れても大丈夫」→「小さな約束を守ることが、自分への信頼と仲間からの信頼を育てる」
- 問い：「続けやすくするために、どんな工夫ができそうですか？」

## 3. 成功の10の原則 × 行動例・考え方

### 第1の原則　あらゆる事柄に目標を設定し、計画的に生きる
- 1日の始まりに、今日の優先順位を決める
- 目標は「いつまでに・何を・どれくらい」まで具体的にする
- 少し背伸びすれば届く目標にする（アチーブメントゾーン）
- 考え方：「毎日忙しくて流されてしまう」→「優先順位を決めた日は、忙しくても自分で選んだ一日になる」
- 問い：「今月、何を達成したいですか？ そのための最初の一歩は？」

### 第2の原則　セルフコントロール能力の習得
- 最優先のことから手をつける
- 自分でコントロールできることに集中する
- 気持ちが揺れたときは、行動（できること）から整える
- 考え方：「あの人が変わってくれれば」→「他人と過去は変えられない。変えられるのは自分と未来」
- 問い：「今、自分でコントロールできることは何ですか？」

### 第3の原則　成功者としての自己概念を形成する
- 身だしなみと持ち場を整える
- 勝利リスト（できたこと）を書きためる
- 約束を守る／自分に正直に生きる
- 考え方：「私はいつも失敗する」→「自分についての見方は事実ではなく解釈。今日からよい解釈を選べる」
- 問い：「最近、自分との約束を守れたことはありますか？」

### 第4の原則　心の法則を使う（信念・期待・因果）
- 「できる」と信じて取り組む
- 人に与えた分だけ豊かになる。先に感謝や手助けを贈る
- 結果には原因がある。うまくいったときも、その原因を振り返る
- 考え方：「どうせうまくいかない」→「信じて取り組むと、行動が変わり、結果が変わる」
- 考え方：「なぜ私ばかり」→「この出来事にも原因と意味がある。ここから何を学べるだろう」
- 問い：「うまくいったとき、その原因は何だったと思いますか？」

### 第5の原則　パワーパートナーの協力を得る能力
- 話を最後まで聴く
- 相手の長所を見つけて、言葉で伝える
- 約束を守る。できない約束をしない
- 考え方：「わかってくれない」→「まず自分から相手を理解しよう。そこから信頼が始まる」
- 問い：「チームの中で、お互いに応援し合える関係をどうつくりたいですか？」

### 第6の原則　専門能力を開発し、真のプロフェッショナルになる
- ひとつの業務を、成果が出るまでやり切る
- 上手な先輩のやり方を見て学ぶ
- 毎日少しずつ、専門分野の勉強を続ける
- 考え方：「先輩のようにはなれない」→「先輩も最初は初心者だった。学べば、自分も同じ道を歩める」
- 問い：「どの分野で、頼られる存在になりたいですか？」

### 第7の原則　過去志向型から未来志向型への変革
- 「なぜできなかったか」より「どうしたらできるか」を考える
- なりたい姿から逆算して、今日やることを決める
- 考え方：「あのときこうしていれば」→「過去は変えられない。過去の経験は、未来をよくするための材料になる」
- 問い：「1年後のなりたい姿から見て、今日できることは何ですか？」

### 第8の原則　一生学び続ける
- 学んだことを、1つ現場で使ってみる
- 院内勉強会で学んだことを、仲間に伝える
- 新しい経験に、開かれた気持ちで向き合う
- 考え方：「もう十分知っている」→「知っていることと、できることは違う。学ぶたびに新しい自分に出会える」
- 問い：「最近、学んで現場で使えたことはありますか？」

### 第9の原則　健康管理を徹底し、エネルギッシュに生きる
- 休憩をきちんと取る
- 自分に合った睡眠・食事・運動のリズムを大切にする
- 明るく、くよくよしすぎない
- 考え方：「休むのは怠けているみたい」→「自分を整えることは、患者さんと仲間に最善を尽くすための準備」
- 問い：「元気に働くために、自分で大切にしていることは何ですか？」
- ※実践の中身は本人の選択です。職場から確認しません。

### 第10の原則　実践主義に徹する
- 学んだら、その日のうちに1つやってみる
- 「いつかやる」を「今日やる」に変える
- 当たり前のことを、毎日やり続ける
- 考え方：「完璧に準備ができてから」→「小さく始めれば、やりながら上手になれる」
- 問い：「今日から始められることは何ですか？」
